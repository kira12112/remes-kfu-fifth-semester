## Operational Principles
1. **Source Grounding**: All educational outputs must be grounded in verified source literature from `source-books/`.
2. **Language Synergy**: User interface in modern English; educational explanations in conversational Egyptian Arabic paired with intact English medical nomenclature.
3. **Autonomous Execution**: Each skill acts as a domain-expert protocol guiding implementation without recurring approval bottlenecks.
